# Kavindu Chandupa — Personal Portfolio

A modern, highly interactive, and responsive portfolio website designed and developed to showcase software engineering projects, technical capabilities, academic journey, certifications, and contact channels.

## 🚀 Live Demo
- [Live Portfolio](https://kavindu-gh.github.io/my-portfolio/)

## 🛠️ Features & UI/UX
- **Dynamic Particle Canvas & Ambient Aura:** Interactive canvas background with fluid animations.
- **Theme & Accent Customizer:** Dark/Light mode toggle with four customizable accent palettes (Violet, Cyan, Pink, Lime).
- **Interactive Command Palette:** Instant keyboard shortcut navigation (<kbd>Ctrl</kbd> + <kbd>K</kbd> / <kbd>Cmd</kbd> + <kbd>K</kbd>).
- **Ambient Sound Toggle:** Relaxing background music experience.
- **Interactive Project Filtering & Search:** Category tabs (Web, Mobile, Full Stack, Desktop Apps, UI/UX) and real-time live search.
- **Interactive Certificate Modal:** Full-screen certificate preview with smooth animations.
- **Academic Timeline:** Complete educational journey from school education to BEng (Hons) Software Engineering.
- **SEO & Structured Data:** Person & WebSite JSON-LD schemas, OpenGraph meta tags, and high-resolution favicons.
